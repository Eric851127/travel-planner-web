# P5 Security Hardening — Apps Script Public Field Whitelist

目的：Apps Script Web App 設為公開讀取前，把 API 回傳內容縮到旅客前端真正需要的資料。API URL 不視為秘密；安全邊界放在「唯讀 + 欄位白名單」。

## Code.gs：PUBLIC_FIELDS

請將目前的 `PUBLIC_FIELDS` 整段替換為：

```js
const PUBLIC_FIELDS = {
  itinerary: [
    'id','date','day','start_time','end_time','group','city','title','description',
    'place_id','transport_id','reservation_id','certainty','order'
  ],
  hotels: [
    'id','city','hotel_name','check_in','check_out','group','address','place_id',
    'google_maps_url','reservation_id'
  ],
  flights: [
    'id','date','airline','flight_no','departure_airport','arrival_airport',
    'departure_time','arrival_time','group','reservation_id'
  ],
  transport: [
    'id','date','type','from_place_id','to_place_id','departure_time','arrival_time',
    'operator','service_no','group','reservation_required','reservation_id'
  ],
  reservations: [
    'id','category','name','date','time','group','status','owner_member_id','deadline',
    'price','currency'
  ],
  places: [
    'id','name','city','category','address','google_maps_url','latitude','longitude',
    'opening_hours','website'
  ],
  members: [
    'id','name','group','role','active'
  ]
};
```

## 明確不公開

- 所有 resources 的 `notes`
- `Hotels.booking_url`
- `Hotels.confirmation_no`
- `Flights.booking_reference`
- `Reservations.booking_url`
- `Reservations.confirmation_no`
- `Transport.url`

`google_maps_url` 與 Places `website` 保留，因為它們是旅客前端的公開導航資料。

## Projection helper

```js
function projectPublicFields_(resource, rows) {
  const allowed = PUBLIC_FIELDS[resource];
  if (!allowed) return rows;

  return rows.map(row => {
    const output = {};
    allowed.forEach(field => {
      if (Object.prototype.hasOwnProperty.call(row, field)) {
        output[field] = row[field];
      }
    });
    return output;
  });
}
```

資料處理順序必須維持：

```text
Google Sheet full row
→ filter
→ sort
→ projectPublicFields_
→ JSON / JSONP response
```

這樣 filter/sort 仍可使用 Sheet 完整欄位，但公開 response 永遠只剩白名單。

## 公開部署前 smoke test

部署新版 Apps Script 後檢查：

- hotels：不得出現 `notes`, `booking_url`, `confirmation_no`
- flights：不得出現 `notes`, `booking_reference`
- reservations：不得出現 `notes`, `booking_url`, `confirmation_no`
- transport：不得出現 `notes`, `url`
- places：不得出現 `notes`
- itinerary：不得出現 `notes`
- itinerary / reservations / places 等正常回傳
- JSONP `?callback=testCallback` 正常

## 原則

Apps Script Web App 設為 Anyone 後，任何知道 endpoint 的人都可能呼叫讀取 API。因此不要依賴隱藏 URL；只允許公開資料從 API 回傳。未來寫入功能不得直接沿用匿名公開讀取權限，應另做受保護的寫入流程。
