# P3.4 — Apps Script Public Field Whitelist

目的：公開 Web App API 只回傳旅客前端真正需要的欄位。即使 Google Sheets 中加入真實確認碼、訂位代碼或私人連結，也不會自動被公開 API 洩漏。

## 1. 在 Code.gs 的 CONFIG 附近加入

```js
const PUBLIC_FIELDS = {
  itinerary: [
    'id','date','day','start_time','end_time','group','city','title','description',
    'place_id','transport_id','reservation_id','certainty','order','notes'
  ],
  hotels: [
    'id','city','hotel_name','check_in','check_out','group','address','place_id',
    'google_maps_url','reservation_id','notes'
  ],
  flights: [
    'id','date','airline','flight_no','departure_airport','arrival_airport',
    'departure_time','arrival_time','group','reservation_id','notes'
  ],
  transport: [
    'id','date','type','from_place_id','to_place_id','departure_time','arrival_time',
    'operator','service_no','group','reservation_required','reservation_id','url','notes'
  ],
  reservations: [
    'id','category','name','date','time','group','status','owner_member_id','deadline',
    'price','currency','notes'
  ],
  places: [
    'id','name','city','category','address','google_maps_url','latitude','longitude',
    'opening_hours','website','notes'
  ],
  members: [
    'id','name','group','role','active'
  ]
};
```

刻意不公開：
- Hotels.booking_url
- Hotels.confirmation_no
- Flights.booking_reference
- Reservations.booking_url
- Reservations.confirmation_no

## 2. 加入 projection helper

```js
function projectPublicFields_(resource, rows) {
  const allowed = PUBLIC_FIELDS[resource];
  if (!allowed) return rows;

  return rows.map(row => {
    const output = {};
    allowed.forEach(field => {
      if (Object.prototype.hasOwnProperty.call(row, field)) {
        output[field] = row[field];
      }
    });
    return output;
  });
}
```

## 3. 在 resource 資料完成 filter + sort 後、送進 success response 前套用

原本概念：

```js
const rows = readResource_(request.resource);
const filtered = filterRows_(rows, request.resource, request.params);
const sorted = sortRows_(filtered, request.resource);
return successResponse_(sorted, startedAt, request);
```

改成：

```js
const rows = readResource_(request.resource);
const filtered = filterRows_(rows, request.resource, request.params);
const sorted = sortRows_(filtered, request.resource);
const publicRows = projectPublicFields_(request.resource, sorted);
return successResponse_(publicRows, startedAt, request);
```

如果你目前 Code.gs 的函式名稱不同，原則不變：**filter/sort 可使用完整 row，但在 jsonResponse_ 前一定要 projection。**

## 4. 安全 smoke tests

部署新版本後檢查：

- `/hotels` 不應出現 `confirmation_no`、`booking_url`
- `/flights` 不應出現 `booking_reference`
- `/reservations` 不應出現 `confirmation_no`、`booking_url`
- `/itinerary?date=2026-12-24` 仍正常
- JSONP `?callback=testCallback` 仍正常

## 注意

前端需要 Google Maps，所以 `google_maps_url` 保留公開。Transport 的 `url` 目前也保留；若未來該欄位放的是私人票券/訂位管理網址，應移出 PUBLIC_FIELDS。
